### What This Shit Can Do

AMW lets people send anonymous messages without creating an account or giving their username, email, or password. May random intro questions muna bago makarating sa actual message form, because apparently kailangan pa nating dagdagan ng konting kalokohan ang simpleng textbox. Pwede rin mag attach ng **images, videos, and links**, with validation and limits para hindi gawing absolute fucking garbage dump ng internet goblins yung website.

May basic anti spam protection din tulad ng **submission cooldown, message length limits, file size limits, duplicate detection, basic bot protection, and server side validation**. Basically, binigyan ko ang internet ng textbox pero nilagyan ko muna ng fucking security department.

### Private Admin Dashboard

May private admin dashboard para sa owner, AKO. Dito ko makikita at ma manage yung anonymous messages, kasama ang **date and time, intro question answers, attachments, submitted links, and basic technical information**. Pwede ring permanently mag delete ng messages kapag spam, basura, or general internet bullshit na walang ambag sa buhay.

### Technical Information

For security and anti spam purposes, maaaring ma record ang **IP address, browser / user agent, requested page, and time of request**. Admin side lang ang makakakita nito. Kaya hindi nito kino claim na 100% anonymous ang website.

Anonymous siya dahil walang account or direct identifying information na kailangan para makapag message. Hindi ibig sabihin na naging fucking invisible ghost ka na sa buong internet.

### Tech Stack

**HTML5, CSS3, Vanilla JavaScript, PHP, MySQL, XAMPP, phpMyAdmin, and InfinityFree.**

Simple stack lang. Walang giant framework, walang 46 dependencies, at walang unnecessary bullshit para lang makapag submit ng isang message.
